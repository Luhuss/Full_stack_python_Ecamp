Respuestas a las preguntas:
Pregunta 1: La migración es el proceso mediante el cual se realiza…
Respuesta correcta:
a. Una transferencia de datos que puede ser de unos sistemas de almacenamiento de datos a otros, de unos formatos de datos a otros, o entre diferentes sistemas informáticos.

El término "migración" se refiere al proceso de transferir datos o estructuras de un sistema a otro, ya sea entre diferentes sistemas de almacenamiento, formatos o sistemas informáticos.

Pregunta 2: Las migraciones se consideran como:
Respuesta correcta:
a. Un sistema de control de versiones para su esquema de base de datos.

En el contexto de Django, las migraciones actúan como un sistema de control de versiones para mantener y modificar el esquema de la base de datos según los cambios realizados en los modelos del proyecto.

Pregunta 3: La definición "Comando que se usa para interactuar con las migraciones, y es responsable de aplicar y no aplicar las migraciones", corresponde a:
Respuesta correcta:
b. Migrate.

El comando migrate se utiliza en Django para aplicar (o deshacer) las migraciones en la base de datos, sincronizando el esquema de la base de datos con los modelos definidos.
