Pregunta 2: ¿Qué permite el fichero __init__.py?
Respuesta correcta:
a. Definir nuestro directorio como un módulo Python válido.

El archivo __init__.py indica que el directorio en el que se encuentra debe tratarse como un módulo Python, permitiendo que otros módulos importen desde él.

Pregunta 3: La afirmación "Permite la gestión de las URLs. Este fichero sería el controlador de la aplicación. Mapea las URLs entrantes a funciones Python definidas en módulos", corresponde a:
Respuesta correcta:
d. urls.py.

El archivo urls.py se utiliza en Django para definir el mapeo de URLs entrantes a vistas o funciones Python que manejan esas solicitudes.

Pregunta 4: ¿Cuál se emplea para activar nuestro servidor web y probar la página de administración?
Respuesta correcta:
b. python manage.py runserver.

El comando python manage.py runserver inicia el servidor de desarrollo de Django, que se utiliza para probar aplicaciones localmente.
